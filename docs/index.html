Everything you copy, kept. One hotkey brings it back, one clipping at a time, and Return pastes it where you were.

curl -fsSL https://raw.githubusercontent.com/ezapmar/blanca/master/install.sh | sh

Then copy something and press Ctrl+Alt+V. Source on GitHub

How it works

  1. A watcher records. Every text copy goes into a history of 99, kept in a file on your machine. Passwords from a password manager are skipped.
  2. A bezel shows one thing. The hotkey opens a small floating terminal with your newest clipping. Press again for the one before.
  3. Return pastes. The bezel closes and the clipping lands where you were typing.

Other ways to install

Arch package, built from the release binary:

git clone https://github.com/ezapmar/blanca && cd blanca/packaging/aur && makepkg -si && blanca setup

From source:

go install github.com/ezapmar/blanca@latest && blanca setup

Needs wl-clipboard, wtype and xdg-terminal-exec, all part of Omarchy.

Configure

~/.config/blanca/config.json. Every key is optional; these are the defaults.

{
  "remember": 99,
  "display": 10,
  "wraparound": false,
  "paste": true,
  "paste_mode": "shift-insert",
  "move_to_top": false,
  "allow_whitespace": false,
  "ignore_large": true,
  "ignore_sensitive": true
}

Set paste_mode to ctrl-v for apps that ignore Shift+Insert.

Honest limits
  • Text only. Images and files are not recorded.
  • Tested on Omarchy with Hyprland. Other wlroots compositors need their own keybind and floating rule.
  • No per-application ignore list; Wayland does not say which window a copy came from.
  • This is v0.1. Expect edges.
