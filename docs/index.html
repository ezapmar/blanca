How it works

göz · the eye

A watcher records

Every text copy goes into a history of 99, kept in a file on your machine. Anything a password manager marks secret is skipped.

yıldız · the star

A bezel shows one thing

The hotkey opens a small floating window with your newest clipping. Press again for the one before.

koçboynuzu · the ram's horn

Return pastes

The bezel closes and the clipping lands where you were typing. Clear, in the menu, forgets the last hour, the last 24 hours, the last month or everything.

On a Mac keyboard Ctrl+Alt+V is Control (⌃) + Option (⌥) + V. Alt is the Option key, and it is Control, not Command. Hold Control and Option, tap V until the clipping you want is showing, and let go: it pastes.

Other ways to install

On a Mac the Omarchy command works too. It puts Blanca.app in Applications and links the blanca command into ~/.local/bin:

curl -fsSL https://raw.githubusercontent.com/ezapmar/blanca/master/install.sh | sh

On Omarchy, a pacman package, so pacman tracks it: x86_64 or aarch64. Download it, then:

sudo pacman -U blanca-x86_64.pkg.tar.zst && blanca setup

The same package, built locally:

git clone https://github.com/ezapmar/blanca && cd blanca/packaging/aur && makepkg -si && blanca setup

From source:

go install github.com/ezapmar/blanca@latest && blanca setup

Or build it from a clone, with Go 1.26 or newer. On Omarchy:

git clone https://github.com/ezapmar/blanca && cd blanca
go build -o ~/.local/bin/blanca . && blanca setup

On macOS, with the Xcode command line tools installed, scripts/macapp builds a universal dist/Blanca.app and a dist/Blanca.dmg beside it. The app is signed ad hoc and targets macOS 13.

git clone https://github.com/ezapmar/blanca && cd blanca
scripts/macapp 0.3.0
cp -R dist/Blanca.app /Applications/ && open /Applications/Blanca.app

On Linux it needs wl-clipboard, wtype and xdg-terminal-exec, all part of Omarchy.

Update

On either system: blanca update, or Check for Updates in the menu. It installs the newest release the way the first one came.

Configure

Use Settings in the menu, or edit ~/.config/blanca/config.json. Every key is optional; these are the defaults.

{
  "remember": 99,
  "display": 10,
  "wraparound": false,
  "paste": true,
  "paste_mode": "shift-insert",
  "sticky": false,
  "move_to_top": false,
  "allow_whitespace": false,
  "ignore_large": true,
  "ignore_sensitive": true
}

Set paste_mode to ctrl-v for apps that ignore Shift+Insert. On macOS, sticky keeps the bezel open when you let go of the keys.

Honest limits
  • Text only. Images and files are not recorded.
  • Tested on Omarchy with Hyprland. Other wlroots compositors need their own keybind and floating rule.
  • No per-application ignore list; Wayland does not say which window a copy came from.
  • Coming from 0.2 on a Mac, allow Blanca under Accessibility once more: macOS treats 0.3 as a new app. Its hotkey is fixed at Ctrl+Alt+V, so quit any other app that uses it first.
  • iPhone copies reach a Mac only. That is Apple's Universal Clipboard, and Linux is not part of it.
  • This is v0.3. Expect edges.
